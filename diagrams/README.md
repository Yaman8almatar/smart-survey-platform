# Diagrams

All diagrams are written as PlantUML sources, one diagram per file, named `<type>-<subject>.puml`
(for example `sequence-submit-response.puml` or `class-core-models.puml`). Each source has its exported
PNG next to it with the same base name (`sequence-submit-response.png`), so the report and slides always
use an image that matches a versioned source.
